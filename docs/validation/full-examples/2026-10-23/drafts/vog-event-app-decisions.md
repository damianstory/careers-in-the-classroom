# Vog by Novus Tech Group

CGY-205-FULL v1 · 2026-10-23

## Classroom question

How can an event app help a visitor choose what to do next?

## Company and Calgary connection

Vog’s portfolio identifies app work for the Calgary Stampede. A May 2024 company notice says Novus Tech Group acquired the assets of Vog Calgary App Developers Inc. and introduced the Vog by Novus brand.

The Calgary Stampede app is the documented local project connection; the legacy project is distinguished from the later brand and ownership change.

## How it works

1. Represent each event with a time, location and category.
2. Ask which constraints matter to the visitor.
3. Filter options and make conflicting times visible.
4. Test changes such as cancellation, missing information or a revised start time.

## Classroom activity

Make a fictional festival list with six events. Write rules to show events after a chosen time and in a chosen category. Add a cancellation and overlapping favourites, then explain what the app can decide automatically and what the visitor must choose.

**Discuss:** Should an app hide an event when information is incomplete, or show it with a clear uncertainty?

**Limits:** The fictional festival model is not the Stampede app’s code or a description of its current features. An asset purchase is not treated as proof that the legal entity, project team or ongoing client relationship stayed unchanged.

## Course connection

CSE1120 · Structured Programming 2: selected outcomes 1, 1.9, 2, 3.1. Conditions, filtering and testing. The company activity is an editorial application.
