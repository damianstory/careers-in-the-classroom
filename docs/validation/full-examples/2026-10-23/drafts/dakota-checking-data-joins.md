# Dakota Analytics

CGY-202-FULL v1 · 2026-10-23

## Classroom question

Why can joining two useful datasets still produce a wrong answer?

## Company and Calgary connection

Dakota Analytics combines data for reporting and dashboards. Its Well Master Menu brings well information together, while its lease-operating summary connects financial and production information.

Dakota Analytics lists a Calgary office on 4th Avenue SW.

## How it works

1. Identify what one row represents in each source table.
2. Choose a key and check whether it is unique where expected.
3. Join related records while preserving unmatched or duplicated cases for review.
4. Compare counts and totals before using the result in a dashboard.

## Classroom activity

Create fictional Assets, Daily Output and Monthly Costs tables. Join all three on Asset ID and notice how a monthly cost can be repeated for every daily-output row. Repair the calculation by aggregating to a common period first, then explain why correct individual values can still produce a misleading total.

**Discuss:** How can a dashboard show the wrong answer even when every source number is correct?

**Limits:** The tables and join error are invented teaching materials. They do not describe an error in Dakota’s products or expose a client database. A shared identifier is useful only when the meaning and granularity of the records are understood.
