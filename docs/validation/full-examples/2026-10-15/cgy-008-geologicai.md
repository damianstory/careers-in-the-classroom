**The problem:** How can several measurements improve an interpretation of a rock sample?

## Classroom tab — proposed copy

The same rock can be measured in several different ways.

An illustrative connection between classroom ideas and sourced work.

1. Drill core is a physical sample from a particular place and depth. Its location and handling matter to interpretation.

2. Different sensors measure different properties: images show appearance, while other measurements add chemical, spectral or geometric information.

3. Software aligns the information so a geoscientist can compare patterns along the core. Interpretation still depends on context and validation.

4. A model extends beyond directly sampled material. New measurements can test the model and change confidence in it.

**Discuss:** If a model is very detailed, does that mean it is well supported everywhere?

**Try thinking it through:** Give students a fictional strip of core with visible colour changes and a second strip of sensor readings. Ask where they would collect an additional sample and what it would test.

**Teacher note:** The strongest answer identifies a specific uncertainty. Do not equate a sensor count with an independently verified mineral concentration.

**Subject connection:** Earth science: samples and minerals; Physics/Chemistry: measurement and spectra. Specific high-school course fit requires review.

**Evidence distinction:** Company process statements come from the sources above. The teaching interpretation, fictional activity and discussion are editorial. No fictional values are company measurements.

## Roles tab — proposed copy

The profiles explain kinds of work. The company-evidence note under each profile states how strongly it is linked to this organization. None of these profiles is a promise of a vacancy.

### Geoscience and interpretation

Explain what rock measurements suggest about geology. Geoscientists combine observations with context and use additional tests where a scan leaves uncertainty.

Typical tasks:

- Describe core and identify changes along it.
- Compare sensor patterns with geological observations or assays.
- Communicate alternative interpretations and uncertainty.

**Works with:** Core technicians, data scientists and exploration teams.

**Classroom connection:** A measurement of a sample is not automatically a measurement of the whole deposit.

**Company evidence:** The company names geoscientists and geological interpretation work.

### Instrument development and testing

Help build and check the equipment that produces measurements. Instrument work joins hardware, software and experiments rather than treating a reading as automatically correct.

Typical tasks:

- Check performance using a known reference.
- Investigate drift, noise or inconsistent readings.
- Document tests so later users know what the instrument can establish.

**Works with:** Scientists, electronics specialists and software developers.

**Classroom connection:** Measurement uncertainty is part of using a tool responsibly.

**Company evidence:** Scanning equipment and operators are stated; these generic testing tasks do not establish a Calgary operator vacancy.

### Software and data systems

Build the tools that move, process and display information. Reliable software needs testing against missing, delayed and unexpected data as well as ideal examples.

Typical tasks:

- Translate a user need into a testable behaviour.
- Build and test a data-processing or display feature.
- Investigate failures and document assumptions about inputs.

**Works with:** Domain experts, designers, users and hardware teams.

**Classroom connection:** An algorithm’s output depends on the quality and meaning of its inputs.

**Company evidence:** Software, analytics and developers are stated work areas.
