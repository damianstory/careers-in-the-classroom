## Question

How can software decide which learning task someone should see next?

A small rule can decide who receives a learning assignment—and mistakes can affect many people.

## How it works

1. Define the condition: identify which learner information matters for an assignment.
2. Evaluate the rule: compare each fictional record with the required conditions.
3. Assign the result: decide which learning task should appear.
4. Retest changes: a changed rule or learner record can change the expected result.

## Classroom use

**Try it:** Create a fictional rule for assigning an introductory course to new staff in a department. Test true, false and missing-value cases and explain the expected behaviour.
**Discuss:** Why should you test a rule with people who should not receive the assignment?
**Teacher note:** Enrollment rules are documented product behaviour. The pseudocode and test data are invented; no AI accuracy or internal implementation is claimed. CSE1120 requires CSE1110.
