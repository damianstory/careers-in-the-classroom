## Question

How do the right signals reach the right control-room screen?

A control-room display is useful only when it shows the information the team needs.

## About the organization

Calgary connection: Userful identifies Calgary research-and-development operations; its headquarters is in Austin.

Company presence and company-wide work are independent claims. Do not present every role or project as Calgary-based.

## How it works

1. Identify the inputs: different sources carry different information.
2. Define the viewing need: the team decides which information belongs on which display.
3. Apply a workflow: software helps route and arrange the selected content.
4. Check exceptions: unavailable or stale inputs need an understandable response.

## Classroom use

**Try it:** Write a fictional rule that selects a display layout for normal and alert conditions. Test what happens when one input is unavailable.
**Discuss:** How could showing more information make a display less useful?
**Teacher note:** This is a contemporary visualization-workflow example. The switching rule is fictional, and no actual customer control-room configuration or Calgary ownership of every feature is claimed. CSE1120 requires CSE1110.
