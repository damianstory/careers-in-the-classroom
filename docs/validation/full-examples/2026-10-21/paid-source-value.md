The practical lesson is to use paid tools when a specific unanswered question could improve a draft, not only when every free route fails. Good triggers include missing local-team evidence, inaccessible original technical pages, useful role details and a bounded check for overlooked sources. A brief paid test can also establish that a provider adds little. One useful recovery, one unhelpful enrichment and two empty index searches are too small a sample to judge any provider universally. They are enough to avoid blanket enrichment of this batch. Continue with different providers or inputs when there is a new concrete reason, rather than repeating these unchanged misses.
