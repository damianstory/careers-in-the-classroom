## What must a computer understand before it can answer a question about a database?

Chata.ai develops tools for asking questions of structured data. Its AutoQL documentation describes translating a question into a database query and validating queries against configured policies.

**Calgary connection:** Chata's company material identifies Calgary as a base for its team. The platform description is company-wide, not evidence of a particular employee's assignment.

## How it works

1. Identify what the question is asking and which records could answer it.
2. Use the structure and relationships of the database to form a query.
3. Check that the requested query is permitted and means what the user intended.
4. Return the result and examine whether it actually answers the question.

**Model limits:** The classroom query is handwritten and checked by students. It does not reproduce AutoQL or demonstrate that AI-generated queries are always accurate or secure.

## Roles and learning pathways

### Software and data

Software developers translate user needs into data structures, rules and interfaces. They test how the system behaves, investigate errors and improve the way people find and use information.

**At this organization:** Translate user needs into data operations, validate the logic and test the result against known examples.

- **Understand the task:** Clarify users, records and the decisions the software needs to support.
- **Build and connect:** Implement data relationships, processing rules and useful interfaces.
- **Test and improve:** Check expected results, missing inputs and access rules, then investigate failures.

**Collaborators:** Product designers, Users, Technical specialists, Operations teams
